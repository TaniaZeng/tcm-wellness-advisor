# 四诊信息采集指引

中医四诊：望、闻、问、切。AI 无法直接接触用户，四诊采集须遵循"能采集则规范采集，不能采集则如实声明局限"的原则。

## 总原则

1. **以"问"为主干**：结构化问诊是信息的主要来源，优先做。
2. **"望"用照片补足**：舌象、面色、皮疹等可请用户拍照上传，这是 AI 四诊中最有价值的补充。
3. **"闻"靠自述**：声音、口气等信息请用户描述。
4. **"切"不替代**：AI 无法把脉。可请用户自述脉搏快慢与规律性，但须声明脉诊须由医师面诊进行，且结论不依赖脉象。
5. 信息不足时按本文件的问诊清单追问，一次最多问 3~4 个问题，避免用户负担过重；用户只想快速建议时可简化为 2~3 问。

## 望诊采集

### 舌象（最重要）

请用户：晨起或白天自然光下，张口伸舌、舌面放松平展，拍一张清晰照片。避免进食染色食物后拍摄。

判读要点（倾向性参考，不下绝对结论）：

| 舌象 | 提示倾向 |
|------|----------|
| 舌淡、苔薄白 | 正常或气虚、阳虚 |
| 舌淡胖大有齿痕、苔白滑 | 阳虚、脾虚湿盛 |
| 舌红、苔少或无苔、或有裂纹 | 阴虚 |
| 舌红、苔黄厚腻 | 湿热 |
| 舌淡白、苔白厚腻 | 痰湿、寒湿 |
| 舌质紫暗或有瘀点瘀斑 | 血瘀 |
| 舌边尖红 | 心肝火旺（常伴情绪问题）|

### 面色与局部

- 面色：萎黄（脾虚/血虚）、苍白（阳虚/气血不足）、潮红（阴虚内热）、晦暗（血瘀）
- 皮疹、痘、疱疹等局部皮肤问题：请拍局部清晰照片，观察颜色（红→热证；不红→寒湿）、形态（水疱→湿；干燥脱屑→燥/血虚）

## 问诊清单（十问歌框架）

| 维度 | 关键问题 |
|------|----------|
| 寒热 | 平时怕冷还是怕热？手脚温度？ |
| 汗 | 出汗多吗？自汗（白天动则汗出）还是盗汗（睡着出汗）？ |
| 头身 | 头晕头痛？身体困重？关节不适？ |
| 二便 | 大便：干/稀/黏马桶/便秘？小便：清长/黄短？ |
| 饮食 | 胃口如何？饭后不适？口干口苦口黏？ |
| 胸腹 | 胸闷？心慌？腹胀？胃痛？ |
| 睡眠 | 入睡难/易醒/多梦/嗜睡？ |
| 情绪 | 情绪状态？压力？易怒/低落/焦虑？ |
| 特殊人群 | 是否孕期/哺乳期？慢性病？正在服药？（决定建议收敛程度） |
| 起居 | 熬夜？运动频次？抽烟饮酒？ |

## 闻诊自述清单

- 声音：说话声音洪亮/低微、是否气短懒言
- 呼吸：是否气粗、易喘
- 口气：口气重（提示胃热/消化不良）？
- 其他：嗳气、矢气多寡

## 切诊的边界

- 可请用户自述：静息脉搏每分钟大约多少次、是否规律（提示性信息，仅供参考）
- **必须声明**：脉象判断需要医师手指触诊，AI 无法进行；本 skill 的判断不依赖脉象，如需脉诊请线下就诊
- 按诊替代：部分信息可请用户自述，如"按肚子哪个位置疼""按压足三里是否有明显酸胀感"

## 采集流程整合

1. 用户首轮描述后，先做初步体质倾向判断（constitutions.md）。
2. 信息不足 → 从问诊清单中挑 3~4 个与判断最相关的维度追问；涉及舌象敏感度高的判断（阴虚/湿热/血瘀）时，主动邀请用户上传舌照。
3. 收到舌照 → 按"望诊采集"判读，把结果并入体质判断，说明这是"倾向性参考，不能替代面诊"。
4. 全程遵守 SKILL.md 安全边界；照片中出现疑似严重皮肤病变（溃烂、快速增大、形状不规则黑痣等）→ 直接建议皮肤科就诊，不做养生判断。

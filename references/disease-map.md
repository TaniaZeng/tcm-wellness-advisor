# 古今病证名对照表

用户用现代语言描述的症状，须先转换为古代病证名，再到 texts/ 语料库检索原文。本表是检索的"翻译层"。

## 使用方法

1. 从用户描述中提炼症状主题。
2. 在下表找到对应的古代病证名（一病多名，全部作为检索关键词）。
3. 用全文搜索工具在 `references/texts/` 目录检索这些关键词（建议带 2 个字以上的词，加上下文行核对）。
4. 命中后通读上下文，确认所述确为该病症，再引用；引用注明书名（篇名若可辨）。
5. 表中没有的病症：先联网搜索"症状 + 中医病名"确认古代对应名，再检索；核实不到就如实说明。

## 对照表

### 睡眠类
- 失眠、入睡难、易醒 → 不寐、不得卧、不得眠、目不瞑、卧不安
- 多梦 → 夜梦纷纭、梦寐不宁
- 嗜睡 → 多寐、嗜卧、但欲寐

### 脾胃类

- 腹泻 → 泄泻、飧泄、下利、溏泄
- 便秘 → 大便难、不更衣、秘结、燥结
- 口黏口苦 → 口苦、胆瘅、口黏

### 皮肤类

- 湿疹类渗出 → 浸淫疮、湿疮、黄水疮
- 手足汗疱疹 → 手足汗、浸淫疮（近似，检索后须核对原文语境）

- 痤疮、痘痘 → 粉刺、面疱、肺风粉刺

### 情志类

- 易怒烦躁 → 肝火、善怒、烦躁

### 虚劳类

- 手脚冰凉 → 手足厥冷、四逆、厥逆

- 头晕 → 眩晕、头眩、目眩、眩冒

### 其他常见

- 眼睛干涩 → 目干涩、雀目（夜盲）、干涩昏花

## 检索注意事项

1. 古籍中的"心下痛"指胃脘部而非心脏；"肠澼"指痢疾；古代"霍乱"多指吐泻交作的急性肠胃病，与现代传染病"霍乱"不同——遇到歧义大的病名须核对原文语境。
2. 命中大量结果时（如"伤寒"），先限定在相关篇章，优先取与用户症状匹配度高的条目。
3. 引用时保留原文，白话解释须谨慎：解释不清的部分注明"原文含义有争议"，不做强行曲解。
4. texts/ 语料库已收录 701 部中医药古籍全文（约 164MB，历代主要医籍），覆盖面广但非"全部存世医籍"；检索不到时用联网搜索补充，并按 classics.md 的核实规则操作。语料文件名带编号前缀（如"437-黄帝内经素问.txt"），按书名关键词检索即可。

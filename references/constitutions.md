# 九种体质辨识要点

根据《中医体质分类与判定》标准，结合用户描述判断体质倾向。多数人是复合体质（2~3 种兼夹），以最突出的表现为主要体质。

## 判定方法

1. 从用户描述中提取关键词：怕冷/怕热、出汗情况、口干口苦、睡眠、大便、情绪、体型、面色、舌象（若用户描述了舌苔）。
2. 对照下表匹配体质倾向，选出最主要 1~2 种。
3. 描述信息不足以判断时，主动追问 2~3 个关键问题（如：平时怕冷还是怕热？容易累吗？大便干还是稀？睡眠如何？），不要凭空猜测。

## 九种体质速查表

| 体质 | 核心特征 | 常见描述关键词 |
|------|----------|----------------|
| 平和质 | 阴阳气血调和，精力充沛 | 睡得好、胃口好、情绪稳、很少生病 |
| 气虚质 | 元气不足，易疲乏 | 容易累、气短懒言、易感冒、易出汗、说话声音低 |
| 阳虚质 | 阳气不足，畏寒 | 怕冷、手脚冰凉、喜热饮、大便稀、夜尿多 |
| 阴虚质 | 阴液亏少，虚热 | 口干咽干、手足心热、盗汗、失眠多梦、便秘、舌红少苔 |
| 痰湿质 | 痰湿凝聚，形体肥胖 | 体胖、腹部松软、口黏、痰多、身体困重、舌苔厚腻 |
| 湿热质 | 湿热内蕴 | 面部油腻、易长痘、口苦口臭、大便黏滞、小便黄、易怒 |
| 血瘀质 | 血行不畅 | 面色晦暗、易有瘀斑、健忘、唇色偏暗、女性痛经血块多 |
| 气郁质 | 气机郁滞，情志不畅 | 情绪低落、易焦虑、爱叹气、胸闷、咽部异物感、失眠 |
| 特禀质 | 先天禀赋特殊 | 过敏体质：易过敏、易打喷嚏、易起荨麻疹、对药物食物花粉敏感 |

## 追问模板（信息不足时使用）

- "您平时比较怕冷还是怕热？"
- "容易觉得累、气短吗？"
- "大便正常吗？偏干还是偏稀、有没有黏马桶？"
- "睡眠质量怎么样？入睡困难还是容易醒？"
- "（女性）月经规律吗？有没有痛经、血块？"

## 复合体质处理

例如"怕冷 + 大便黏 + 爱长痘" → 阳虚兼湿热。调理建议以主要体质为主，兼顾次要体质，并提示两种体质的调理方向可能有冲突（如阳虚忌寒凉、湿热忌温补），给出折中方案。
